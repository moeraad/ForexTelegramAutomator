CopyTrades SaaS · Point 18

MVP Scope Cut — what ships v1

Thinnest end-to-end loop: a subscriber pays, connects a broker account with zero install, and a curated channel's signals are auto-traded with safe management. Everything operator-assisted, one execution path.

The decisive cut

✂️

MetaApi-managed ONLY for v1 — defer the self-hosted EA to v1.1

Zero-install onboarding, server-side Python (testable, no MetaEditor), per-account COGS trivial at beta scale (~$11 × 20 ≈ $220/mo). Shipping one execution path — the managed one — is what makes the MVP small. It deletes whole subsystems from v1:

EA multi-tenant rework EA token auth WebSocket doorbell layer EA versioning Install guide EA-local caps
